## 🚀 核心特性

1. **内置 + 云端双模式 M3U 订阅清单**：
   - 出厂内置 ，无需网络配置，首次开机秒开。
   - 自动在后台从你的 GitHub 仓库（）检测并同步最新 ，后期维护频道或更换失效源**无需重新打包安装 APK**！
2. **多线路毫秒级切换**：
   - 每个频道聚合了 IPv6 高清专线、移动广电专线、公网备用源等多条线路。
   - 播放卡顿或失效时**自动尝试下一条线路**。
   - 遥控器**按 ◄ 或 ► 键**随时手动切换线路。
3. **雷鸟/TCL 电视遥控器极简交互**：
   - **▲ / ▼ 键**：快速平滑换台，底部悬浮 OSD 卡片展示频道号、台名、当前线路。
   - **◄ / ► 键**：无缝切换当前频道的不同播放源线路。
   - **OK / 确认键**：呼出左侧全屏毛玻璃半透明选台列表（左侧分类、右侧频道列表）。
   - **数字键 (0-9)**：输入台号直接跳转（如  -> CCTV-1， -> 重庆卫视）。
   - **菜单键 (MENU)**：一键手动拉取并刷新最新云端订阅源。
   - **返回键 (BACK)**：关闭节目列表；播放界面双击返回防误触退出。
   - **开机记忆**：自动保存上次观看的频道与线路，下次启动直接播放。
4. **高性能 ExoPlayer 硬解播放引擎**：
   - 适配 Android TV 硬件解码，画质清晰、CPU 与内存占用极低（安装包仅约 9MB）。
